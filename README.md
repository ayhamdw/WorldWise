World Wise
===========

World Wise is a web application for tracking the countries and cities you've visited. 
You can log each place you’ve been to and leave notes about your trip.

Built using React, CSS Modules, Node.js, Leaflet, and React Router.

-----------------------------------------
🌍 Features
-----------------------------------------
- Add countries and cities you've visited
- Attach personal notes for each visit
- Interactive map using Leaflet
- Filter and browse all your travel entries
- Responsive design using CSS Modules
- Routing with React Router
- Backend support using Node.js (optional for data persistence)

-----------------------------------------
🛠 Tech Stack
-----------------------------------------
- React
- CSS Modules
- Leaflet.js
- Node.js (for backend/server)
- React Router
- JavaScript

-----------------------------------------
📦 Installation
-----------------------------------------
1. Clone the repository
   git clone https://github.com/your-username/world-wise.git

2. Navigate into the project folder
   cd world-wise

3. Install frontend dependencies
   npm install

4. Run the development server
   npm run dev

5. Build for production
   npm run build

-----------------------------------------
📌 Notes
-----------------------------------------
- Travel data can be saved locally or connected to a Node.js backend.
- The map interface is powered by Leaflet with marker pins for each visited location.
- React Router is used to manage navigation between the map, list, and detail views.
